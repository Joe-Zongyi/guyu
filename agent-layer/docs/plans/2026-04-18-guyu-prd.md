# 谷雨 Guyu PRD

## 1. 产品概述

- 产品名：谷雨 Guyu
- 定位：面向家庭绿植用户的 AI 养护助手。
- 核心价值：
  - 拍照识别植物品种
  - 生成今日养护建议
  - 用日历和成长记录帮助用户持续照顾植物
  - 结合抖音内容流提供养护视频参考

## 2. 背景与机会

家庭绿植用户常见问题：

- 不知道植物品种
- 不清楚浇水、光照、施肥等方法
- 容易忘记日常养护
- 缺少记录和反馈，难以持续坚持

谷雨希望解决：

- 降低绿植养护门槛
- 把养护知识转成每日可执行建议
- 用记录、奖励、内容推荐提升留存

## 3. 功能设计

### 3.1 绿植识别与养护指导

- 用户上传植物图片，系统识别品种
- 输出植物名称、基础信息、习性和养护建议
- 结合天气生成“今天该做什么”

### 3.2 日历式展示与提醒

- 首页用日历/卡片方式展示：
  - 今日日期
  - 今日天气
  - 植物状态
  - 今日养护建议
- 重点是让用户一眼知道今天该做的事

### 3.3 3D 图片重建与收集

- 记录用户每日上传的植物图片
- 展示植物成长时间轴
- 提供 3D 或伪 3D 展示，体现植物变化
- 连续记录若干天后解锁植物卡片奖励

### 3.4 关联抖音视频流

- 单独页面推荐相关绿植养护视频
- 推荐维度可基于植物品种、天气或养护场景

## 4. 四部分分工细化

### 4.1 前端与美术设计

#### 工作内容

- 负责整体视觉风格和页面设计
- 实现首页、识别页、成长页、视频页
- 对接后端接口和 3D 展示组件
- 处理 loading、空状态、异常状态

#### 重点页面

- 首页：天气、植物卡片、今日建议、打卡入口
- 识别页：上传图片、识别结果、建档入口
- 成长页：时间轴、3D 展示、奖励卡片
- 视频页：相关养护视频流

#### 交付物

- 高保真设计稿
- 前端页面实现
- 基础设计规范

### 4.2 植物识别 Agent

#### 工作内容

- 识别植物品种
- 输出结构化结果
- 结合天气生成养护建议
- 提供适合前端展示的短文本

#### 输入

- 植物图片
- 日期
- 天气

#### 输出

- 植物名称
- 识别置信度
- 植物简介
- 养护建议
- 风险提醒

#### 交付物

- Agent 接口
- 输出 JSON 结构
- 测试样例

### 4.3 3D 重建

#### 工作内容

- 确定 MVP 技术路线
- 基于图片生成 3D 或伪 3D 展示结果
- 输出前端可加载的模型或展示资源

#### 建议方案

- 优先做单植物 3D 展示或时间轴 + 轻量 3D
- 若重建不稳定，用单模型切换或动画兜底

#### 交付物

- 采集规范
- 模型或渲染资源
- Demo 样例

### 4.4 后端

#### 工作内容

- 负责用户、植物档案、记录、奖励等数据管理
- 提供上传、识别、首页、记录、视频推荐接口
- 对接天气服务、Agent 服务、3D 资源

#### 核心接口

- 上传图片
- 植物识别
- 创建植物档案
- 获取首页数据
- 提交每日记录
- 获取成长记录
- 获取奖励卡片
- 获取视频推荐

#### 交付物

- API 文档
- 数据表设计
- 可联调服务
